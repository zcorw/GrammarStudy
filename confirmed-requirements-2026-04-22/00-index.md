## 当前结论摘要

- 产品类型：日语文法学习练习网站
- 平台形态：移动端 Web 应用，采用轻量 PWA
- 技术方向：前端 TypeScript，后端 Python + FastAPI
- 产品核心流程：
  `用户输入文法 -> 优先检索已有公共卡片 -> 未命中时 AI 生成结构化学习卡片 -> 用户学习/练习 -> 创建完成后进入公共库复用`
- 游客能力：查看文法卡片、做选择题
- 登录用户能力：创建文法、自由造句 AI 点评、同步学习数据
- 首版目标：易维护、小规模正式使用
