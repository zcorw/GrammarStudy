# 项目概览

## 当前状态

项目处于架构发现阶段，正在通过分阶段问答补全平台、范围、领域模型、UI、架构、依赖、API 约定与测试交付方案。

## 已确认约定

- 交互语言：中文
- 文档语言：中文
- 代码注释语言：英文
- 汇报风格：详细

## 已确认产品与技术方向

- 产品方向：文法卡片检索、AI 辅助创建、练习点评
- 产品定位：面向移动端的日语文法学习网站，沉淀可复用公共文法卡片
- 首发平台：`PWA`
- 前端：`Vite + React + TypeScript`
- 后端：`Python + FastAPI + SQLAlchemy + Alembic`
- 数据库：`PostgreSQL`
- 仓库：`Monorepo + pnpm workspace`
- 部署基线：`Docker`
- 当前目标：易维护的上线版

## 已确认业务范围

- 核心用户：日语学习者
- 首版主闭环：检索 -> 复用 -> AI 创建 -> 学习/练习 -> 入公共库沉淀
- 首版包含：推荐、搜索、卡片查看、创建流程、选择题、自由造句点评、学习记录
- 首版不含：管理后台、公共库治理、复杂推荐、向量检索、支付、社交、教师端
- 当前量化验收指标：暂不定义

## 已确认流程与领域基线

- 游客可查看卡片和做选择题；登录用户可创建文法、追加提问、使用自由造句点评、同步学习数据
- 搜索优先直达最佳卡片，相近文法通过左右滑动切换
- 创建流程中的追加提问只修改当前卡片，不生成新卡片
- 核心领域对象：`GrammarEntry`、`CreationSession`、`PracticeQuestion`、`SentenceFeedback`、`UserProgress`
- 首版允许重复或近重复卡片存在，去重治理后置
- 登录用户需要一个聚合页面，用于展示自己创建的文法与收藏的文法

## 已确认 UI 基线

- 首页提供推荐文法与搜索学习入口，登录用户额外突出快速创建
- 输入文法后先进入“检索结果/推荐复用”状态，再决定学习已有内容或继续创建
- 选择题练习采用独立页面，不嵌在文法详情页内
- 自由造句 AI 点评采用独立页面
- 登录用户有“我的文法页”，聚合展示创建和收藏内容，不强制 tab 区分
- 首页视觉优先级为推荐内容优先
- 检索结果页与文法详情页尽量复用同一展示骨架
- 创建流程采用分步骤结构
- 我的文法页默认按最近学习/浏览排序
- 注册与登录统一采用邮箱 + 密码，首版不做邮箱验证，可结合邀请码或管理员审核控制准入
- 选择题练习为独立页面
- `ui-static/` 完全采用 `preview-site/` 镜像版本

## 已确认 Starter Package 选型

- 前端框架：`Vite`
- 后端 ORM 与迁移：`SQLAlchemy + Alembic`
- 管理审核首版先手工改数据库状态
- AI 首版先接单一供应商
- 已补首个 Alembic 初始迁移
- 文法推荐、检索、详情读取已切到 PostgreSQL 仓储
