# Setup 阶段记录：语言与输出约定

## 已确认

- 交互语言：中文
- 项目文档语言：中文
- 代码注释语言：英文
- 汇报风格：详细

## 决策

- 后续各阶段默认使用中文提问与总结
- 阶段文档与架构文档默认使用中文维护
- 代码中的必要注释默认使用英文
- 每个阶段保留更详细的理由、假设、风险和缺失信息

## 假设

- 当前工作区中的已有文档属于本项目的前期架构草案
- 若后续阶段出现与既有草案冲突的决策，以新的确认结果为准，并同步回写文档

## 风险

- 当前仅确认了协作与记录方式，尚未确认平台、部署环境、成本约束与交付范围
- 已有架构草案可能包含未经当前操作人明确确认的历史假设

## 缺失信息

- 项目名称
- 目标平台与部署方式
- 技术栈偏好与限制
- 是否延续现有架构草案
